                Desktop & CLI
              

            

            
Montoring runs as a standalone desktop app — launch it from your application menu or with montoring-app.

            

              
              
            

            

              
bash — montoring

              
montoring status     # service status
montoring logs       # tail app logs
montoring restart    # restart dashboard
montoring update     # self-update
montoring open       # open in browser

sudo ./update.sh     # reinstall code changes
sudo ./update.sh --remote
