System & Kernel

              checking…
            

            
Repair system and kernel software, run a full system upgrade (including new kernels), and tune performance — one tool, every step verified.

            

          

          

            not checked yet
            

              
            

          

        


        

          

            

              
              Fix All System & Kernel Issues
              scanning…
            

            —
          

          
The one-click tool that fixes every detected system & kernel software issue: interrupted package transactions, broken dependencies, kernel module maps, missing/stale initramfs images, the boot menu, firmware metadata — then refreshes package lists, runs the full system upgrade (new kernels included), removes obsolete packages and cleans caches. Each step is reported individually and verified.

          

          

            
            
            
          

          

            
monitoring maintain --fix-all

            

          

          
⚠ A full upgrade can take several minutes and may finish with a reboot required — nothing is rebooted automatically.

        


        

          

            

              

                
                System Upgrade
                checking…
              

            

            
Refreshes package lists and installs every available update — including new kernels (apt full-upgrade / dnf upgrade / zypper dist-upgrade / pacman -Syu / apk upgrade).

            

            

              
              
            

            

              
monitoring full-upgrade

              

            

            
⚠ A reboot is required to activate updated kernels and libraries — the Overview will keep warning until you do.

          


          

            

              

                
                System & Kernel Repair
              

              scanning…
            

            
Fixes the software layer under the OS: interrupted package transactions, broken dependency state, kernel module maps and missing/stale initramfs images.

            

            

              
            

            

              
monitoring maintain --repair

              

            

          

        


        

          

            

              

                
                Performance Tuning
              

              —
            

            
Reversible kernel-level tuning: CPU governor, memory swap tendency (vm.swappiness) and I/O scheduler. Applied live and persisted across reboots; one-click revert restores your exact original values.

            

            

            

            

              
              
            

            

              
monitoring perf

                Desktop & CLI
              

            

            
Monitoring runs as a standalone desktop app — launch it from your application menu or with monitoring-app.

            

              
              
            

            

              
bash — monitoring

              
monitoring status     # service status
monitoring logs       # tail app logs
monitoring restart    # restart dashboard
monitoring update     # self-update
monitoring open       # open in browser

sudo ./update.sh     # reinstall code changes
sudo ./update.sh --remote
./update.sh --check  # read-only update check
